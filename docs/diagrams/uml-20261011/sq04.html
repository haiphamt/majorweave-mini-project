SQ04 Lưu cloud và ngăn ghi đè

Đối chiếu code ngày 11/10/2026 · EF29, EF30, EF31, EF33, EF34, EF36, EF44

Điều kiện và nhánh cần nhớ

  • RPC nằm phía server; client không có quyền INSERT/UPDATE trực tiếp. RLS SELECT bảo vệ đọc, không thay kiểm tra owner của RPC.
  • SQL kiểm tra shape cơ bản; client validate workspace. Không tuyên bố SQL xác minh mọi quy tắc planner.
  • Phiên đổi sau RPC có thể làm client từ chối ACK dù server đã commit; dữ liệu của scope cũ không được đưa sang scope mới.
  • Advisory transaction lock và row lock tuần tự hóa các lần save cùng tài khoản.
