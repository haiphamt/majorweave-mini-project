## Danh mục 18 hướng và nền tảng

### Backend Developer

Xây API, xử lý dữ liệu và phát triển phần máy chủ của ứng dụng.

**Cần chuẩn bị:** Lập trình, OOP, DSA, mạng, OS, nguyên lý hệ thống, Git, HTTP, cơ sở dữ liệu và kiểm thử; chọn Node.js / Express, Python / FastAPI hoặc Java / Spring Boot để làm kế hoạch thực hành.

**Roadmap tham khảo:** [Backend](https://roadmap.sh/backend)

### Frontend Developer

Xây giao diện web có tương tác, dễ sử dụng và phù hợp nhiều màn hình.

**Cần chuẩn bị:** HTML, CSS, JavaScript, khả năng truy cập và giao tiếp với API; thiết kế giao diện chưa thay cho nền tảng lập trình.

**Roadmap tham khảo:** [Frontend](https://roadmap.sh/frontend)

### Full-stack Developer

Kết nối giao diện, API và dữ liệu thành một ứng dụng hoàn chỉnh.

**Cần chuẩn bị:** Học từng phần frontend và backend trước, sau đó tích hợp và triển khai một dự án nhỏ.

**Roadmap tham khảo:** [Full Stack](https://roadmap.sh/full-stack)

### Mobile Developer

Khám phá hai lộ trình riêng cho Android và iOS; chọn một nền tảng để bắt đầu.

**Cần chuẩn bị:** Lập trình, quản lý trạng thái, vòng đời ứng dụng, lưu dữ liệu và API.

**Roadmap tham khảo:** [Android](https://roadmap.sh/android) · [iOS](https://roadmap.sh/ios)

### Game Developer

Lập trình cơ chế chơi, tương tác và các hệ thống của một trò chơi.

**Cần chuẩn bị:** Lập trình, toán cho game, một game engine và tổ chức dự án; đồ họa game là một hướng riêng.

**Roadmap tham khảo:** [Game Developer](https://roadmap.sh/game-developer)

### QA / Test Automation

Thiết kế kiểm thử và tự động hóa việc kiểm tra chất lượng phần mềm.

**Cần chuẩn bị:** Phân tích yêu cầu, thiết kế ca kiểm thử, API, SQL và lập trình khi làm kiểm thử tự động.

**Roadmap tham khảo:** [QA](https://roadmap.sh/qa)

### DevOps / SRE

Tự động hóa triển khai, quan sát và duy trì độ tin cậy của dịch vụ.

**Cần chuẩn bị:** Linux, mạng, Git, scripting, container và triển khai; SRE mở rộng thêm vận hành và độ tin cậy.

**Roadmap tham khảo:** [DevOps](https://roadmap.sh/devops)

### Network Engineer

Thiết kế, cấu hình và xử lý sự cố kết nối, routing và dịch vụ mạng.

**Cần chuẩn bị:** Mạng máy tính, giao thức, Linux, cấu hình thiết bị và thực hành mô phỏng mạng.

**Roadmap tham khảo:** [Network Engineer](https://roadmap.sh/network-engineer)

### Cyber Security

Xây nền tảng bảo vệ hệ thống trước khi chọn chuyên sâu phòng thủ hoặc kiểm thử.

**Cần chuẩn bị:** Mạng, hệ điều hành, lập trình và nguyên tắc an toàn thông tin; thực hành trong môi trường được phép.

**Roadmap tham khảo:** [Cyber Security](https://roadmap.sh/cyber-security)

### Data Analyst

Phân tích và trực quan hóa dữ liệu để hỗ trợ quyết định.

**Cần chuẩn bị:** SQL, bảng tính, thống kê, làm sạch dữ liệu và diễn giải kết quả theo bối cảnh nghiệp vụ.

**Roadmap tham khảo:** [Data Analyst](https://roadmap.sh/data-analyst)

### BI Analyst

Phân tích dữ liệu kinh doanh và xây dashboard phục vụ quyết định của tổ chức.

**Cần chuẩn bị:** SQL, mô hình dữ liệu, ETL và một công cụ BI; chú trọng nhu cầu báo cáo của người dùng.

**Roadmap tham khảo:** [BI Analyst](https://roadmap.sh/bi-analyst)

### Data Engineer

Xây pipeline thu thập, lưu trữ và xử lý dữ liệu đáng tin cậy.

**Cần chuẩn bị:** Lập trình, SQL, cơ sở dữ liệu, ETL, chất lượng dữ liệu và nền tảng xử lý dữ liệu.

**Roadmap tham khảo:** [Data Engineer](https://roadmap.sh/data-engineer)

### Data Scientist

Kết hợp thống kê, thử nghiệm và mô hình dự báo để khai thác dữ liệu.

**Cần chuẩn bị:** Python, xác suất thống kê, đại số tuyến tính, đánh giá mô hình và kiến thức của lĩnh vực ứng dụng.

**Roadmap tham khảo:** [AI and Data Scientist](https://roadmap.sh/ai-data-scientist)

### Machine Learning

Xây, đánh giá và tích hợp mô hình học máy vào ứng dụng.

**Cần chuẩn bị:** Toán, thống kê, lập trình, xử lý dữ liệu, học máy và đánh giá mô hình; dùng API AI chưa tương đương huấn luyện mô hình.

**Roadmap tham khảo:** [Machine Learning](https://roadmap.sh/machine-learning)

### MLOps Engineer

Đưa mô hình vào vận hành và quản lý dữ liệu, phiên bản, chất lượng mô hình.

**Cần chuẩn bị:** Học máy cùng Linux, container, CI / CD, phục vụ mô hình và quan sát; là bước mở rộng sau nền tảng ML.

**Roadmap tham khảo:** [MLOps](https://roadmap.sh/mlops)

### AI Engineer

Xây ứng dụng AI, đánh giá kết quả và tích hợp mô hình vào sản phẩm.

**Cần chuẩn bị:** Python, API, dữ liệu, đánh giá ứng dụng, bảo mật và vận hành.

**Roadmap tham khảo:** [AI Engineer](https://roadmap.sh/ai-engineer)

### UX Design

Nghiên cứu người dùng, thiết kế luồng và giao diện dễ sử dụng.

**Cần chuẩn bị:** Nghiên cứu người dùng, bố cục, tương tác, prototype và đánh giá khả năng sử dụng.

**Roadmap tham khảo:** [UX Design](https://roadmap.sh/ux-design)

### Business Analyst

Khảo sát nhu cầu, phân tích quy trình và quản lý yêu cầu của tổ chức.

**Cần chuẩn bị:** Khảo sát, mô hình hóa quy trình, user story, ưu tiên và xác nhận yêu cầu.

**Roadmap tham khảo:** [IIBA — Business Analysis](https://www.iiba.org/business-analysis-blogs/what-is-business-analysis/)
